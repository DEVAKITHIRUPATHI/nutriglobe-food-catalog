### **Prompt: Global & Indian Nutrition Facts App (Offline + Online)**  
**App Name:** *NutriGlobe* (or custom name)  
**Platforms:** Android (Kotlin/Jetpack Compose), iOS (SwiftUI), Web (Flutter/React).  

---

### **Core Features**  
1. **Multilingual Support**  
   - **Languages:**  
     - **Global:** English, Spanish, French, Arabic, Mandarin, Portuguese, Russian, Japanese, German, Swahili.  
     - **Indian:** Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, Punjabi, Odia.  
   - **UI:** Dropdown language switcher + auto-detect device language.  
   - **Content:** All text (UI labels, descriptions) and nutrition data translatable.  

2. **Offline-First Data**  
   - **Local Storage:** SQLite (Mobile) / IndexedDB (Web) to cache:  
     - 500+ fruits/vegetables/ingredients (100g metrics).  
     - High-compression images (WebP) for offline use.  
   - **Sync:** Background update when online (Firebase/FastAPI).  

3. **Nutrition Database**  
   - **Per 100g Standardized Data** (Example):  
     ```json
     {
       "id": "mango_india",
       "name": { "en": "Mango", "hi": "आम", "ta": "மாம்பழம்" },
       "origin": "India",
       "calories": 60,
       "carbs": 15g,
       "vitamins": { "C": "60% DV", "A": "25% DV" },
       "image_local": "assets/mango.webp",
       "image_online": "https://.../mango.jpg",
       "allergens": ["vegan", "gluten-free"],
       "fun_fact": { "en": "National fruit of India!", "hi": "भारत का राष्ट्रीय फल!" }
     }
     ```
   - **Regional Highlights:**  
     - **Global:** Quinoa, Avocado, Kale, Salmon.  
     - **Indian:** Mango (Alphonso), Jackfruit, Amla, Turmeric.  

4. **E-Commerce UI**  
   - **Views:**  
     - *Grid/List*: Filter by diet (Keto, Vegan), region, or nutrient (High Iron).  
     - *AR Scan*: Scan food labels to fetch nutrition (ML Kit/TensorFlow Lite).  
   - **Cart:** Save favorites, export shopping lists.  

5. **Tech Stack**  
   - **Backend:** Firebase (Online) / Custom API (Python + MongoDB).  
   - **Offline Sync:** WorkManager (Android), Background Fetch (iOS).  
   - **i18n:** Flutter Intl / Android Resources.
